# Казино Vert: слоты, колесо и лимиты

Социальная надстройка над Vert Games: слоты и колесо на внутренние монеты V,
ежедневные задания, дневной лимит потерь и самоисключение. **Реальных ставок и
вывода денег нет** — только развлечение, 18+.

## Что есть в продукте

| Файл | Назначение |
| --- | --- |
| `casino.html` | Страница «Рулетка Vert»: слоты, колесо, история, правила, лимиты |
| `assets/vg/js/casino.js` | Клиент: анимации барабанов и колеса, ставки, лимиты |
| `casino_logic.py` | Серверная математика: секторы, символы, веса, RTP, лимиты вращений |
| `server.py` | `/api/casino/*`: `rules`, `wheel`, `slots`, `history`, `limits` |
| `db.py` | `casino_history`, `casino_limits`, атомарные ставки с блокировкой кошелька |
| `tools/test_economy.py` | Тесты экономики: атомарность, идемпотентность, лимиты казино |
| `tools/check_platform.py` | Сквозные проверки казино, лимитов и самоисключения |

## Запуск и проверка

```bash
.venv/bin/python server.py            # http://localhost:8000/casino.html
.venv/bin/python tools/check_platform.py          # SQLite
DATABASE_URL=postgresql://... .venv/bin/python tools/check_platform.py
```

## Экономика

Всё считается на сервере (`casino_logic.py` + `game_catalog.py`):

* ставки 5 / 10 / 20 / 25 / 50 / 100 V, дневной лимит потерь по умолчанию 500 V;
* колесо: 1 бесплатное вращение в сутки + 5 платных, счётчики сбрасываются в
  00:00 UTC (`/api/casino/rules` → `wheelLimits`);
* слоты: три в ряд платят множитель символа, пара — 40 % ставки;
* RTP и вероятности отдаются в `/api/casino/rules` и показаны на странице;
* настройки в админке: `casino_enabled`, `wheel_enabled`, `slots_enabled`,
  `min_stake`, `max_stake`, `wheel_free_daily`, `wheel_paid_daily`.

## 1. Где живёт баланс

Баланс **полностью серверный** (PostgreSQL): `wallets.balance` с
`CHECK (balance >= 0)`, каждая операция пишется в `transactions`, ставки и
выплаты казино — в `casino_history`. Браузер не может ни придумать баланс, ни
подделать результат: клиент присылает только игру и ставку, всё остальное
считает сервер внутри транзакции с блокировкой строки кошелька.
Подробности — `DATABASE_SETUP.md`, `RENDER_DATABASE_SETUP.md`.

Пакеты V за реальные деньги удалены из продукта: `SHOP_PACKS = {}`, в магазине
только косметика. Вебхуки платёжных провайдеров (`/api/shop/webhook/*`) остались
заглушками и возвращают `PACKS_DISABLED`.

## 2. Ответственная игра

* Дневной лимит потерь: `POST /api/casino/limits {daily}` — после достижения
  ставки отклоняются до 00:00 UTC.
* Самоисключение: `excludeUntil` блокирует казино на выбранный срок, снять
  досрочно нельзя.
* На странице всегда видны правила, RTP и надпись «18+, только виртуальные V».

## 3. Ежедневные задания

Прогресс пишет сервер: игры — `progress_task(..., 'play')`, ставки казино —
`progress_task(..., 'casino')`. Награда выдаётся один раз в сутки через
`POST /api/tasks/claim`, повод для начисления `task:<uid>:<task>:<дата>`.
Стартовый набор заданий — `game_catalog.DAILY_TASKS`, редактируется в админке.

## 4. Что проверить вручную

1. `casino.html` на телефоне (390 px): табы, барабаны, ставки, модалка лимитов.
2. Ставка списывается сразу, выигрыш приходит в той же транзакции; история и
   баланс в шапке обновляются.
3. Шестое платное вращение колеса блокируется, бесплатное — одно в сутки.
4. Дневной лимит потерь и самоисключение реально блокируют ставки.
5. `admin.html`: настройки казино, каталог игр (`redline` виден только админу).
