# Админ-панель: пароль, вход и разделы

Админка — обычная страница `/admin.html`, но доступ к ней и ко всем её данным
проверяется **только на сервере**. Пароль администратора живёт в переменной
окружения, в коде и в браузере его нет.

## 1. Как задать пароль на Render

1. Откройте <https://dashboard.render.com> и выберите сервис Vert Games
   (Blueprint `render.yaml` → сервис `vert-games`).
2. Слева **Environment** (переменные окружения).
3. Найдите строку **`ADMIN_PASSWORD`**. В `render.yaml` у неё стоит `sync: false` —
   это значит, что значение не хранится в репозитории и вводится в панели.
   Если строки нет — **Add Environment Variable**, имя `ADMIN_PASSWORD`
   (ровно так, заглавными).
4. В поле **Value** введите пароль:
   * минимум 12–16 символов, буквы обоих регистров, цифры и символы;
   * не используйте ник, почту, название игры и слова вроде `admin`, `vert`;
   * пароль вводится один раз и никуда не дублируется — запишите его в менеджер
     паролей.
5. **Save Changes** — Render сам пересоберёт и перезапустит сервис
   (обычно 1–3 минуты). Переменная читается при каждом входе, поэтому
   достаточно одного рестарта.
6. Проверьте: откройте `https://ваш-домен/admin.html`, поле «Пароль
   администратора» → должны попасть в панель. Неверный пароль — красное
   сообщение; 6 неудачных попыток за 15 минут блокируют вход (rate-limit).

`ADMIN_USERNAME` (по умолчанию `admin`) — только подпись в журнале действий,
на вход не влияет.

### Как поменять пароль

Environment → `ADMIN_PASSWORD` → **Edit** → новый пароль (значение не
отображается, поэтому просто перезапишите его) → Save Changes → дождитесь
рестарта. Старые админ-сессии живут максимум 8 часов; чтобы отозвать их сразу,
нажмите «Выйти» в панели или перезапустите сервис.

### Если пароль не задан

Вход отвечает `503 ADMIN_NOT_CONFIGURED` — это защита от «админки без пароля».
Резервный вариант: если `ADMIN_PASSWORD` пуст, сервер использует `SECRET_KEY`
(он генерируется Render'ом автоматически). Полагаться на это не стоит: `SECRET_KEY`
служебный, его неудобно помнить — задайте отдельный `ADMIN_PASSWORD`.

### Локальный запуск

```bash
export ADMIN_PASSWORD='локальный-пароль-только-для-разработки'
.venv/bin/python server.py
# http://localhost:8000/admin.html
```

`.env`/`render.yaml` в git с настоящим паролем не коммитим.

## 2. Что делает сервер

| Механизм | Где | Что даёт |
|---|---|---|
| Пароль только из env | `server.py` → `admin_login` | в исходниках и фронтенде нет ни пароля, ни дефолта |
| Сравнение за постоянное время | `_admin_password_ok` (`hmac.compare_digest`) | нельзя подобрать пароль по времени ответа |
| Капча | `captcha.verify` (Turnstile) | бот не перебирает пароль |
| Rate-limit входа | `rate('admin_login', ADMIN_LOGIN_RATE=6, 900)` | 6 попыток / 15 минут на IP |
| Сессия | `admin_sessions`: в БД только `digest(token)` | украденная БД не даёт входа |
| Срок жизни | `ADMIN_SESSION_TTL = 8 часов` | сессия истекает сама |
| Кука | `HttpOnly`, `SameSite=Lax`, `Secure` на https | JS не читает токен, чужая страница не отправит запрос |
| Проверка прав | `@admin_required` → `is_admin_request()` | каждый `/api/admin/*` отвечает `401` без сессии |
| Журнал | `admin_log` (кто, что, когда, хеш IP) | видно все действия и неудачные входы |
| CSRF | `X-CSRF-Token` (double-submit cookie) | POST нельзя отправить с чужого сайта |

Обычный игрок с валидной сессией админку не получает: `is_admin_request()`
смотрит на серверную админ-сессию и на `users.is_admin`/`role` в БД.

## 3. Разделы панели

* **Обзор** — пользователи, монеты, запуски, топ балансов, последние действия.
* **Пользователи** — поиск, профиль, баланс (+ / − / установить), бан/разбан,
  выдача прав администратора, история операций и ставок.
* **Игры** — включить/выключить награды, не удаляя файлы игр.
* **Каталог** — товары магазина (косметика), достижения, ежедневные задания,
  фоны профиля.
* **Операции** — все транзакции монет (одна строка = одна операция).
* **Казино** — настройки (вкл/выкл, мин/макс ставка, RTP) и **история рулетки и
  слотов**: ставка и выплата отдельными числами, итог за спин.
* **Блоки стройки** — какие материалы доступны в палитре MiniCraft. Снятый блок
  исчезает из палитры (игра берёт список из `/api/game/blocks`), уже
  поставленные блоки остаются в мире.
* **Ошибки** — сообщения игроков («Сообщить об ошибке» в плеере): текст,
  страница, игра, автор; кнопка «Закрыть» помечает сообщение решённым.
* **Подозрительное** — факты за 24 часа: неудачные входы в админку (с хешем IP),
  крупные операции (≥ 1000 V), самый большой чистый выигрыш в казино, новые
  аккаунты. Ничего не блокируется автоматически — решает человек.
* **Журнал** — действия администраторов.

Все данные этих разделов отдаются сервером только после проверки админ-сессии:
в HTML/JS нет ни пароля, ни списка пользователей, ни балансов.

## 4. Проверка

```bash
python -m unittest tools.test_admin_secure -v
```

Тест проверяет: вход без `ADMIN_PASSWORD` → `503`; неверный пароль → `401` и
запись в журнал; перебор → `429`; истечение сессии → `401`; каждый
`/api/admin/*` без сессии → `401`; обычный игрок → `401`; пароля нет ни в одной
странице, скрипте или ответе API; действия пишутся в `admin_log`; сообщение об
ошибке сохраняется/закрывается; список блоков проверяется по справочнику id.
