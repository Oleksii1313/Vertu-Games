# MiniCraft 3D — расширение геймплея (18.11.2026)

Только игра `games/minicraft.html` плюс минимальные правки каталога, моста
`platform.js` и один новый серверный эндпоинт. Остальные десять игр, главная,
каталог, профили, логин и глобальный дизайн не затронуты.

## Что появилось в мире

| Сущность | Сколько | Как работает |
| --- | --- | --- |
| Деревни | 6 | Дома (стены, окна, двери, крыши), дороги, фермы с заборами, колодцы, фонари, лавки; площадка выравнивается, деревья сносятся |
| Жители | 15 (2–3 на деревню) | Ходят по своим делам, убегают от монстров (с обходом препятствий), при подходе подсказывают дорогу к сундуку и дают 1 монету (не больше 6 раз за сессию) |
| Сундуки | 21 | Открываются один раз за сессию: 3 монеты («house»/«coins») или 5 («treasure»); крышка открывается, летят частицы |
| Зелёные V-монеты | 130 в мире + подсыпка | Дороги, фермы, леса, деревни, опасные окраины; каждая даёт **ровно 3 V** |
| Монстры | до 8 / 14 / 20 по минутам | Зомби, скелеты (стреляют), пауки (быстрые); высота капа ниже на телефоне |
| Босс | 1 | Гигантский зомби после 150-й секунды, 80 HP, отдаёт горсть монет |

Мир, физика, управление, камера и генерация ландшафта остались прежними:
новые объекты используют существующие `cs/ui/Rt/ir`, `Ht`, `F`.
Таймер по-прежнему 180 секунд (`Og`).

## Монеты и начисление V

* Монета — плоский воксельный жетон (BoxGeometry 0.44 × 0.44 × 0.1) с
  процедурной текстурой 64 × 64: ярко-зелёный корпус, тёмная окантовка,
  светлый ободок и крупная белая «V»; `emissive` даёт лёгкое свечение,
  анимация — вращение, покачивание и пульс рядом с игроком.
* Сбор: `F.coinsCollected += 1`, `F.score += 3`, всплывающее «+3 V»,
  частицы, обновление HUD.
* HUD: счётчик монет, сумма V, сундуки, убийства, номер волны (или `BOSS`).

## Награда: как считается

Клиент не может «нарисовать» баланс — сумму считает сервер:

1. билет (`anticheat.issue`, HMAC, TTL 30 мин) запрашивается при открытии игры;
2. в конце сессии (таймер, смерть → «Завершить сессию», выход, закрытие
   плеера) игра шлёт `{type:'minicraftSession', coins, time, kills, chests,
   sessionId}`;
3. `platform.js` вызывает `POST /api/games/session/claim`, передавая билет;
4. сервер (`server.py::game_session_claim`) проверяет подпись и принадлежность
   билета, обрезает число монет лимитом каталога (150) и реальной скоростью
   сбора (2 монеты в секунду, минимум 3; заход короче 5 секунд не оплачивается),
   считает `coins × 3`, применяет суточный лимит 450 V и пишет выплату с
   ключом `mcs:<sid>` — повтор того же билета не платит второй раз;
5. ответ возвращается игре (`minicraftSessionResult`), баланс в шапке
   обновляется, экран итогов показывает «На баланс зачислено N V».

Сценарий из ТЗ (538 → 598) покрыт тестом `tools/test_session_claim.py`.

### Ограничение, о котором нужно знать

Закрытие плеера кнопкой «Назад» раньше обнуляло сессию: iframe сразу получал
`about:blank`. Теперь `closeGame()` для MiniCraft сначала шлёт игре `vg:flush`
и ждёт 600 мс; другие игры закрываются как раньше. Если браузер убил вкладку
аварийно, невыплаченный итог теряется — это ограничение клиентской игры,
а не сервера.

## Проверка

```
python tools/check_platform.py         # 227 / 0
python tools/test_rewards.py           # 10 OK
python tools/test_anticheat.py         # 25 OK
python tools/test_session_claim.py     # 14 OK (новый)
python tools/test_economy.py           # 18 OK
python tools/test_wheel.py             # 37 OK
npm install jsdom && node tools/test_minicraft.js   # 60 / 60 (новый)
```

`tools/test_minicraft.js` запускает настоящий рантайм игры в jsdom с
заглушкой WebGL: проверяются деревни, монеты (+3 V), сундуки, жители и их
подсказки, убегание от монстров, урон, убийства, волны по минутам, босс,
смерть, экран итогов, запрос выплаты, повторная сессия и закрытие плеера.

Чего проверить нельзя без браузера: реальный WebGL-рендер, FPS на телефоне,
вид монеты и деревень глазами игрока. Текстура монеты отрисована отдельно
(PIL-копия тех же команд) и выглядит как зелёный жетон с белой «V».
