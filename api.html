API

HTTP API платформы

JSON-API для сайта и игр. Аутентификация — сессионная cookie vg_session (HttpOnly, SameSite=Lax). Изменяющие запросы требуют Content-Type: application/json. Все суммы V-монет определяются сервером: клиент не может начислить монеты сам.

МетодПутьОписание
GET/api/sessionТекущая сессия, пользователь, конфигурация капчи и каталог.
POST/api/auth/registerРегистрация: {"username", "password", "turnstileToken", "startedAt"}.
POST/api/auth/loginВход: {"username", "password", "turnstileToken"}.
POST/api/auth/logoutВыход и удаление сессии.
POST/api/auth/passwordСмена пароля: {"current", "password"}. Все другие сессии закрываются.
GET/api/meПрофиль, статистика, достижения, покупки и история операций.
GET/api/balanceТекущий серверный баланс V.
GET/api/ledger?limit=30История операций с монетами.
GET/api/gamesКаталог игр и агрегированная статистика.
POST/api/games/playОтметить запуск игры: {"game"}.
POST/api/games/rewardНаграда за событие: {"game", "receipt"}. Сумму и лимит задаёт сервер.
GET/api/shopКаталог магазина и статус покупок.
POST/api/shop/buyПокупка предмета: {"item"}.
POST/api/shop/equipНадеть предмет: {"item"}.
GET/api/casino/rulesПравила казино, вероятности, RTP и лимиты.

POST/api/admin/balanceИзменение баланса: {"username", "delta"|"set", "reason"}.

Ошибки

Все ошибки возвращаются как {"ok":false,"code":"...","msg":"..."} с HTTP-статусом 4xx/5xx. Коды: AUTH_REQUIRED, RATE_LIMIT, NO_FUNDS, LIMIT, CAPTCHA_FAILED, ADMIN_AUTH_REQUIRED.
